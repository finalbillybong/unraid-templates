# Unraid templates

Community Apps templates maintained by finalbillybong.

## Kitchen Cupboard

[Kitchen Cupboard](https://github.com/finalbillybong/Kitchen-cupboard) is a self-hosted recipe library, weekly meal planner and collaborative shopping list for households. It is currently in beta and uses the `finalbillybong/kitchen-cupboard:latest` image for x86-64 servers.

- [Docker template](kitchen-cupboard.xml)
- [Installation, configuration and backups](https://github.com/finalbillybong/Kitchen-cupboard#unraid-setup)
- [Support and bug reports](https://github.com/finalbillybong/Kitchen-cupboard/issues)

The first account becomes admin even with registration disabled. Set a unique random Secret Key of at least 32 characters, configure Public URL, and persist `/app/data`. See the application README for the full setup.
